What it does

One skill. Every kind of source.

Point PageGuide at a document, a site, your code or your logs. It finds the evidence and hands you the link.

Cite PDFs & papers

Ask a question about a paper and get the passage back, highlighted in yellow on its real page — sharp in Skim, not a blurry screenshot.

/pg read paper.pdf and explain its motivation

Find facts on the web

A real browser run points an orange arrow at the exact words on the page. Press O for the untouched shot, N for the next match.

/pg find 2 mangos on amazon.com

Explain a codebase

Turn a wall of files into a diagram where every box links to the exact lines it describes. Check each claim at its source.

/pg explain the code in this repo

Read your logs

Point it at a build or error log and ask why something failed. The answer cites the line it came from, so you can jump straight to it.

/pg find why the command failed in ./build.log

Watch your Git diff

pg diff --watch keeps a plain-language summary of your working tree — one cited bullet per changed file, each linking to the exact lines. It never edits or commits.

pg diff --watch

Step-by-step with a big arrow

Ask "how do I…" and PageGuide draws a big arrow on your screen, one control at a time. Nothing is clicked for you; every step is saved as a shot.

/pg show me step by step how to add a filter in Numbers

Get started

Running in about a minute.

You need a Mac or Linux machine with Python 3.9+ and Node.js 22.20+. Easiest of all: let your agent install it for you.

01

Install the skill

Adds the /pg command to Claude Code, Codex, OpenCode or Pi.

npx skills add tinxai/pageguide_terminal -g
02

Set up PDFs & websites

Creates a private Python environment and downloads a browser. Safe to run again.

python3 ~/.claude/skills/pg/scripts/pageguide.py setup --launcher
03

Try your first citation

Click the citation it returns — the passage opens highlighted on its page.

/pg read examples/papers/pageguide.pdf and cite it
